功能规划

完整说明见同目录 FEATURES.md。桌面版已经把扫描、打开 agent、CLI 任务做成可执行：

1. 项目库

扫描带 hyperframes.json 的目录，按 BRIEF / pin / 工作流编目。左侧是自定义项目（可新建、可从全部拖入）和文件夹树（可 pin、点击后摊平子目录）。

2. 调整修改

选中工程后进入工作台：BRIEF、时长画幅、只读时间轴、快照、文件。动作条生成 preview / lint / check / snapshot / render，不内置运动编辑器。

3. 打开 Grok Build / Codex

工作目录必须是该工程根。grok --cwd "<path>" 与 codex --cd "<path>"。确认后会真正打开 agent，工作目录落在工程根。

4. CLI 小功能

preview、lint、check、snapshot、render、doctor、init，以及 upgrade 探针与 compositions 列表。全部走同一套命令构造器。

5. 封面 / 扫描 / 进程

扫描后按时长等距抽 9 帧（含第一帧和最后一帧），封面可切单图 / 四宫格 / 九宫格。悬停卡片看大图。右侧常驻 HyperFrames 占用（CPU / 内存 / 显卡百分比），旁边一键清理和暂停渲染。
